# Breeding

Breeding is how you unlock new slime types. It happens in the world: no machine and no randomness. The same parents with the same block nearby always give the same baby.

## How to breed

1. Get two **adult** slimes (size 2 or more). See [Slimes](./slimes) for growing them.
2. Place the **catalyst block** within 2 blocks of them, if the recipe needs one.
3. Right-click each slime with its own food. Each one then looks for a partner for 30 seconds.
4. When they meet, a size 1 baby appears between them.

Both parents then rest for **5 minutes** before they can breed again. Feeding a resting slime does nothing; the game tells you how long it still needs.

::: tip Catalysts are not used up
Unless a recipe says otherwise, the catalyst block stays where it is, so one block can serve many breedings.
:::

## Which baby you get

The game checks the two parents and the blocks around them, in this order:

1. A recipe for these two parents **whose catalyst is within 2 blocks**.
2. A recipe for these two parents that **needs no catalyst**.
3. If both parents are the **same type**, a baby of that type.

If none of these match, the slimes don't breed and nothing is used up except the food. Order doesn't matter: Stone + Coal is the same as Coal + Stone.

This is why several recipes can share the same parents. Two Stone Slimes make Andesite next to Andesite, Granite next to Granite, Diorite next to Diorite, and more Stone Slimes with no catalyst at all.

## Planning a route

Every recipe only uses slimes from lower tiers, so you can always work your way up. For example, to get an Iron Slime:

1. **Coal**: Stone + Oak, next to a Block of Coal (or take a pair from a [Slime Shrine](./slimy-land#slime-shrines))
2. **Copper**: Stone + Coal, next to a Block of Copper
3. **Iron**: Copper + Stone, next to a Block of Iron

The [slime types](./slime-types) page lists every type with its parents, so you can trace any route backwards.
